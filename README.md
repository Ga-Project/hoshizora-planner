# 星空撮影プランナー

天の川の中心（いて座付近）が、**その夜いつ・どの方角に・どの高さで**見えるかを一画面で示す、
日本語の星景撮影プランナーです。撮影地に着いてから「山影に隠れて撮れない」「もう沈んでいた」を
避けるため、出発前に今夜の見頃を確かめられます。ブラウザだけで動き、登録は不要です。

## 何ができるか

- 観測地（主要都市から選ぶ／緯度・経度を手動入力）と日付を選ぶと、その夜の天の川の見頃を計算します。
- 「今夜のおすすめ」として、見頃のピーク時刻・方角（16方位＋方位角）・高度を大きく表示します。
- 夜のタイムライン（夕暮れ→天体夜→夜明け）の上に、天の川中心の高度推移を重ねて表示します。
- 空が十分に暗くなる時間（天文薄明の終わり）と、月明かりの影響（月齢・照度）も示します。

## 使い方

1. 「観測地」を選ぶ（一覧にない場所は「緯度・経度を手動で入力」）。
2. 「日付」を選ぶ（初期値は今日）。
3. 表示された「今夜のおすすめ」とタイムラインで、撮影の時間帯と方角を確認する。

見頃がない夜（天の川中心が暗い時間に十分な高度まで昇らない季節・緯度）は、その旨を表示します。

## できないこと・注意

- 天文計算による**可視の目安**です。天候・雲・光害・周囲の地形（遮り）は考慮しません。
- 太陽・月の位置は近似計算のため、時刻・方角は数分角〜1度程度の誤差を含みます。
- 時刻はすべて日本標準時（JST）で表示します。

## 開発

Next.js（App Router）。`out/` への static export で配信するためサーバランタイムは不要です。
天文計算は `lib/astro.mjs` にまとまっており、UI とテストの双方から同じ関数を使います。

```bash
./setup.sh                 # 依存の導入
pnpm dev                   # http://localhost:3000（ホットリロード）
pnpm test                  # node --test（天文計算の検証を含む）
pnpm build                 # next build → out/ に静的書き出し
```
